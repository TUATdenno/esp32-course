    6. アナログ入力¶

    このステップでやること¶

    可変抵抗（ボリューム）のつまみの位置を電圧として読み取り、その値で LED の明るさを変えます。 センサーの多くは、測った量を電圧として出力します。アナログ入力は、センサーを使うための基本になります。

    画像：つまみを回すと LED の明るさが変わる様子

    前提ステップ・使う部品¶

    • 前提：3. シリアルモニタ、5. PWM
    • 部品：
      • ステップ2の LED の回路
      • 可変抵抗（10 kΩ）× 1
      • ジャンパワイヤ

    配線¶

    可変抵抗には足が 3 本あります。両端の足に 3.3 V と GND を、中央の足を ESP32 のピンにつなぎます。

    ESP32 接続先
    GPIO13 抵抗 220 Ω → LED → GND（ステップ2と同じ）
    3V3 可変抵抗の端の足
    GPIO32 可変抵抗の中央の足
    GND 可変抵抗のもう一方の端の足

    画像：配線図

    画像：実際の配線写真

    5 V につながない

    ESP32 のピンに入力できる電圧は 3.3 V まで です。可変抵抗の端を 5V（VIN）ピンにつなぐと、ESP32 が壊れることがあります。必ず 3V3 ピンにつないでください。

    仕組み¶

    可変抵抗は、つまみを回すと中央の足の位置が変わり、両端の電圧（3.3 V と 0 V）の間の電圧を取り出せる部品です。

    ESP32 には、電圧を数値に変換する AD 変換器（ADC） が入っています。ESP32 の ADC は 12 ビット で、0〜3.3 V の電圧を 0〜4095 の数値に変換します。

    コード¶

    src/main.cpp
    #include <Arduino.h>

const int LED_PIN = 13;
const int POT_PIN = 32;  // 可変抵抗をつないだピン

void setup() {
  Serial.begin(115200);
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  int raw = analogRead(POT_PIN);           // 0〜4095
  int mv = analogReadMilliVolts(POT_PIN);  // 電圧（mV）
  int duty = map(raw, 0, 4095, 0, 255);    // 0〜4095 を 0〜255 に変換する

  analogWrite(LED_PIN, duty);
  Serial.printf("raw = %4d, voltage = %4d mV, duty = %3d\n", raw, mv, duty);
  delay(100);
}
    • analogRead(ピン)：ピンの電圧を 0〜4095 の数値で返します
    • analogReadMilliVolts(ピン)：ピンの電圧をミリボルト単位で返します（ESP32 の補正値を使って計算されます）
    • map(値, 元の最小, 元の最大, 新しい最小, 新しい最大)：値の範囲を比例計算で変換します

    ESP32 の ADC の癖

    ESP32 の ADC は、0 V 付近と 3.3 V 付近の電圧を正確に測れません。つまみを端まで回しても 0 や 4095 にならなかったり、途中で一気に変わったりするのはこのためです。 正確に電圧を測りたい場合は、analogReadMilliVolts を使うか、外付けの ADC の IC を使います。

    ADC1 と ADC2

    ESP32 の ADC には ADC1（GPIO32〜39）と ADC2（GPIO0、2、4、12〜15、25〜27）の 2 つがあります。ADC2 は Wi-Fi を使っている間は使えません。 この講座では、Wi-Fi と組み合わせても使えるように、ADC1 の GPIO32 を使っています。

    発展課題¶

    • シリアルモニタに、電圧を V 単位（小数点以下 2 桁）で表示する（ヒント：%.2f）
    • つまみの位置で、LED の点滅の速さを変える
    • つまみが半分より右なら LED を点灯、左なら消灯にする

    うまくいかないとき¶

    値が 0 か 4095 のまま変わらない
    • 可変抵抗の中央の足が GPIO32 につながっているか確認してください
    • 両端の足が 3V3 と GND につながっているか確認してください
    値がふらつく

    ADC の値は、ノイズで数十程度ふらつくのが普通です。気になる場合は、何回か読み取った値の平均をとってください。

    チェックポイント¶

    チェックポイント

    つまみを回して LED の明るさが変わり、シリアルモニタに値が表示されたら、先輩に見せて進捗表にチェックをもらってください。
