    4. ボタン入力¶

    このステップでやること¶

    タクトスイッチ（押しボタン）の状態を読み取り、押すたびに LED の点灯・消灯を切り替えます。マイコンで「入力」を扱う最初のステップです。

    画像：ボタンを押すと LED が切り替わる様子

    前提ステップ・使う部品¶

    • 前提：3. シリアルモニタ
    • 部品：
      • ステップ2の LED の回路
      • タクトスイッチ × 1
      • ジャンパワイヤ

    配線¶

    ESP32 接続先
    GPIO13 抵抗 220 Ω → LED → GND（ステップ2と同じ）
    GPIO4 タクトスイッチの片側
    GND タクトスイッチのもう片側

    画像：配線図

    画像：実際の配線写真

    タクトスイッチの足

    タクトスイッチには足が 4 本あり、向かい合う 2 本ずつが内部でつながっています。対角の足を使うと、向きを間違えても確実にスイッチとして使えます。

    プルアップ¶

    ボタンが押されていないとき、GPIO4 はどこにもつながっていない状態になります。この状態のピンは電圧が定まらず（フローティング）、読み取るたびに HIGH と LOW がランダムに変わってしまいます。

    そこで、ピンを抵抗を通して 3.3 V につないでおきます。これを プルアップ と言います。

    • ボタンを押していない：抵抗を通して 3.3 V につながる → HIGH
    • ボタンを押している：GND に直接つながる → LOW

    ESP32 はプルアップ抵抗を内蔵しているので、pinMode(ピン, INPUT_PULLUP) と書くだけで使えます。押したときに LOW になる 点に注意してください。

    画像：プルアップ回路の図（押していないとき・押したとき）

    まずは、ボタンを押している間だけ LED が点灯するプログラムで動作を確認します。

    void setup() {
  pinMode(LED_PIN, OUTPUT);
  pinMode(BUTTON_PIN, INPUT_PULLUP);  // 内蔵プルアップを有効にした入力
}

void loop() {
  if (digitalRead(BUTTON_PIN) == LOW) {  // 押されている
    digitalWrite(LED_PIN, HIGH);
  } else {
    digitalWrite(LED_PIN, LOW);
  }
}

    押すたびに切り替える¶

    「押すたびに切り替える」には、ボタンが 押された瞬間（HIGH から LOW に変わったとき）を検出する必要があります。前回の状態を覚えておき、今回の状態と比べます。

    src/main.cpp
    #include <Arduino.h>

const int LED_PIN = 13;
const int BUTTON_PIN = 4;

bool lastState = HIGH;  // 前回読み取ったボタンの状態
bool ledOn = false;     // LED が点灯しているか

void setup() {
  Serial.begin(115200);
  pinMode(LED_PIN, OUTPUT);
  pinMode(BUTTON_PIN, INPUT_PULLUP);
}

void loop() {
  bool state = digitalRead(BUTTON_PIN);

  // 前回は離していて、今回は押している → 押された瞬間
  if (lastState == HIGH && state == LOW) {
    ledOn = !ledOn;
    digitalWrite(LED_PIN, ledOn ? HIGH : LOW);
    Serial.println(ledOn ? "LED ON" : "LED OFF");
    delay(50);  // チャタリング対策
  }

  lastState = state;
}

    チャタリング¶

    delay(50); を消して動かすと、1回押しただけなのに LED が何度も切り替わることがあります。これは、スイッチの接点が押した瞬間に細かく跳ね返り、短時間に HIGH と LOW を何度も繰り返すためです。この現象を チャタリング と言います。

    画像：チャタリングの波形（オシロスコープで測ったもの）

    ここでは、押された瞬間を検出したあとに 50 ms 待ち、跳ね返りが収まるまで次の読み取りをしないことで対策しています。

    チャタリングの長さ

    チャタリングが続く時間はスイッチによって異なりますが、一般的なタクトスイッチで数 ms 程度です。そのため、10〜50 ms ほど待てば十分に対策できます。 ハードウェアで対策する場合は、抵抗とコンデンサで作るローパスフィルタや、シュミットトリガ入力の IC を使います。

    発展課題¶

    • ボタンを押した回数を数えて、シリアルモニタに表示する
    • ボタンを離した瞬間（LOW から HIGH に変わったとき）にも、シリアルモニタに表示する
    • ボタンを 1 秒以上長押ししたときだけ LED を切り替える（ヒント：押された瞬間の millis() を覚えておく）

    うまくいかないとき¶

    ボタンを押しても反応しない
    • タクトスイッチの足の向きを確認してください。対角の足を使うと確実です
    • pinMode が INPUT_PULLUP になっているか確認してください
    押していないのに勝手に切り替わる

    INPUT_PULLUP ではなく INPUT になっていると、ピンがフローティングになって勝手に切り替わります。

    チェックポイント

    ボタンを押すたびに LED が切り替わったら、先輩に見せて進捗表にチェックをもらってください。
