    3. シリアルモニタ¶

    このステップでやること¶

    シリアル通信を使って、ESP32 と PC の間で文字列をやり取りします。

    • ESP32 → PC：変数の値やプログラムの状態を表示する（デバッグ に使う）
    • PC → ESP32：キーボードから送った文字で LED を操作する

    マイコンには画面がないので、プログラムの中で何が起きているかを知る手段としてシリアルモニタは欠かせません。

    前提ステップ・使う部品¶

    • 前提：2. Lチカ
    • 部品：ステップ2の LED の回路をそのまま使います

    配線¶

    ステップ2と同じです（GPIO13 → 抵抗 → LED → GND）。

    値を表示する¶

    まずは、変数の値をシリアルモニタに表示する書き方を確認します。

    int count = 0;

void loop() {
  Serial.print("count = ");   // 改行しない
  Serial.println(count);      // 最後に改行する
  Serial.printf("count = %d, time = %lu ms\n", count, millis());  // 書式を指定して表示
  count++;
  delay(1000);
}
    関数 動作
    Serial.print(値) 値を表示する（改行しない）
    Serial.println(値) 値を表示して改行する
    Serial.printf(書式, 値, ...) C 言語の printf と同じ書式で表示する

    millis() は、電源が入ってからの経過時間をミリ秒で返す関数です。7. delay を使わない書き方 で詳しく扱います。

    PC から ESP32 を操作する¶

    次は逆向きに、PC から送った文字を ESP32 で受け取ります。

    src/main.cpp
    #include <Arduino.h>

const int LED_PIN = 13;

void setup() {
  Serial.begin(115200);
  pinMode(LED_PIN, OUTPUT);
  Serial.println("1: LED ON / 0: LED OFF");
}

void loop() {
  // 受信したデータがあるか確認する
  if (Serial.available() > 0) {
    char c = Serial.read();  // 1文字読み取る

    if (c == '1') {
      digitalWrite(LED_PIN, HIGH);
      Serial.println("LED ON");
    } else if (c == '0') {
      digitalWrite(LED_PIN, LOW);
      Serial.println("LED OFF");
    } else if (c != '\r' && c != '\n') {  // 改行コードは無視する
      Serial.printf("unknown command: %c\n", c);
    }
  }
}
    • Serial.available()：受信して、まだ読んでいない文字の数を返します。0 なら何も届いていません
    • Serial.read()：受信した文字を1文字取り出します

    Tera Term のウィンドウ上でキーボードの 1 や 0 を押すと、その文字が ESP32 に送られます。

    入力した文字が画面に表示されない

    Tera Term は、初期設定では自分が入力した文字を画面に表示しません（送信はされています）。表示したい場合は、「設定」→「端末」の「ローカルエコー」にチェックを入れてください。

    シリアル通信

    データを1ビットずつ順番に（直列に）送る通信方式です。対して、複数の線で同時に送る方式をパラレル通信と言います。 ESP32 と CH340 の間は、送信（TX）と受信（RX）の2本の線でつながっていて、それぞれの向きに同時に通信できます。

    デバッグの考え方¶

    プログラムが思いどおりに動かないときは、どこまで想定どおりに動いているか をシリアルモニタで確認するのが基本です。

    • 処理の途中に Serial.println("ここまで来た"); を入れて、どこで止まっているかを調べる
    • 変数の値を表示して、想定した値になっているかを確かめる
    • 条件分岐の中に表示を入れて、どちらの分岐に入っているかを確かめる

    この方法は「print デバッグ」と呼ばれ、マイコン開発で最もよく使われるデバッグ手法です。

    発展課題¶

    • t を送ると、LED の状態を反転（点灯中なら消灯）させる
    • s を送ると、現在の LED の状態と millis() の値を表示する
    • 2〜9 の数字を送ると、その回数だけ LED を点滅させる（ヒント：c - '0' で数値に変換できる）

    うまくいかないとき¶

    文字を送っても反応しない
    • Tera Term のウィンドウをクリックして選択した状態で、キーを押してください
    • Tera Term が正しいポートに接続されているか確認してください
    • 書き込み後に Tera Term を再接続したか確認してください
    unknown command と表示される

    全角入力になっていないか確認してください。半角で送る必要があります。
