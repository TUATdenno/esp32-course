# 5. PWM

## このステップでやること

PWM という方法で、LED の明るさを段階的に変えます。LED がゆっくり明るくなり、ゆっくり暗くなる動作を作ります。
PWM は、モーターの速度制御やサーボモーターの角度制御にも使われる重要な技術です。

## 前提ステップ・使う部品

- 前提：[2. Lチカ](02-blink.md)
- 部品：ステップ2の LED の回路をそのまま使います

## 配線

ステップ2と同じです（GPIO13 → 抵抗 → LED → GND）。

## PWM の仕組み

`digitalWrite` で出せるのは、3.3 V か 0 V の 2 通りだけです。そこで、**HIGH と LOW を高速に切り替え、HIGH の時間の割合を変える** ことで、平均的な電圧を変えます。これを **PWM**（Pulse Width Modulation、パルス幅変調）と言います。

1 周期のうち HIGH の時間が占める割合を **デューティ比** と言います。

| デューティ比 | 平均電圧 | LED の明るさ |
|---|---|---|
| 0 % | 0 V | 消灯 |
| 25 % | 約 0.8 V 相当 | 暗い |
| 50 % | 約 1.7 V 相当 | 中くらい |
| 100 % | 3.3 V | 最大 |

!!! todo "画像：デューティ比ごとの波形の図"

切り替えが十分に速い（この講座の設定では 1 秒間に 1000 回）ので、人の目には点滅ではなく明るさの違いとして見えます。

## コード

```cpp title="src/main.cpp"
#include <Arduino.h>

const int LED_PIN = 13;

void setup() {
  pinMode(LED_PIN, OUTPUT);
}

void loop() {
  // だんだん明るくする
  for (int duty = 0; duty <= 255; duty++) {
    analogWrite(LED_PIN, duty);  // デューティ比を 0〜255 で指定する
    delay(5);
  }
  // だんだん暗くする
  for (int duty = 255; duty >= 0; duty--) {
    analogWrite(LED_PIN, duty);
    delay(5);
  }
}
```

- `analogWrite(ピン, 値)`：PWM を出力します。値は 0〜255 で、0 がデューティ比 0 %、255 が 100 % です
- 値の範囲が 0〜255 なのは、デューティ比を **8 ビット**（2<sup>8</sup> = 256 段階）で表しているためです

!!! mame "LEDC"
    ESP32 は PWM を出力するための専用の回路を持っていて、**LEDC**（LED Control）と呼ばれています。`analogWrite` は内部でこの LEDC を使っています。
    LEDC を直接使うと、周波数や分解能（ビット数）を細かく指定できます。ただし、LEDC の関数名や引数は Arduino core のバージョンによって異なるので、調べるときはバージョンに注意してください。

!!! mame "人の目と明るさ"
    人の目は暗いところの変化に敏感なので、デューティ比を一定の割合で増やしても、明るさは一定の割合で変化しているようには見えません。前半で急に明るくなり、後半はあまり変わらないように見えます。
    自然に見せたい場合は、デューティ比を 2 乗などの曲線で変化させます（ガンマ補正）。

## 発展課題

- [ ] `delay(5)` の値を変えて、明滅の速さを変える
- [ ] 明るさを「消灯 → 暗い → 中くらい → 最大」の 4 段階で切り替える
- [ ] [4. ボタン入力](04-button.md) の回路を追加し、ボタンを押すたびに明るさが 1 段階ずつ上がるようにする

## うまくいかないとき

??? question "LED の明るさが変わらない（点灯か消灯しかしない）"
    `analogWrite` ではなく `digitalWrite` になっていないか確認してください。
