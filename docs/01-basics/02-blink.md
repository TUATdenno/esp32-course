# 2. Lチカ

## このステップでやること

ブレッドボードに LED をつなぎ、ESP32 から点滅させます。マイコンで「出力」を扱う最初のステップです。

## 前提ステップ・使う部品

- 部品：

    - ブレッドボード
    - LED（赤など）× 1
    - 抵抗 220 Ω × 1
    - ジャンパワイヤ

## ブレッドボードの仕組み

ブレッドボードは、はんだ付けをせずに回路を組むための板です。穴の内部は、決まった向きで金属板によってつながっています。

- 中央の溝をはさんだ **縦 5 穴ずつ** がつながっている（列ごとに独立している）
- 両端の **赤線・青線の列（電源ライン）** は、横方向に長くつながっている。赤を電源、青を GND に使うのが一般的

!!! todo "画像：ブレッドボードの内部のつながりを示した図"

ESP32 ボードは、中央の溝をまたぐように挿します。こうすると左右のピンがそれぞれ別の列になり、ショートしません。

## 配線

| ESP32 | 接続先 |
|---|---|
| GPIO13 | 抵抗 220 Ω → LED のアノード（足が長い方） |
| GND | LED のカソード（足が短い方） |

!!! warning "LED の向きに注意"
    LED には極性があり、逆向きにつなぐと点灯しません。**足が長い方がアノード（＋）**、短い方がカソード（−）です。足を切りそろえた LED は、本体のふちが平らになっている側がカソードです。

ピン番号は、ボードの横に印刷されている `13` や `IO13` などの表記を見て探します。ピンの位置は [付録：ピン配置](../appendix/pins.md) にもまとめています。

## コード

```cpp title="src/main.cpp"
#include <Arduino.h>

const int LED_PIN = 13;  // LED をつないだピン

void setup() {
  pinMode(LED_PIN, OUTPUT);  // ピンを出力モードにする
}

void loop() {
  digitalWrite(LED_PIN, HIGH);  // 3.3 V を出す → 点灯
  delay(500);
  digitalWrite(LED_PIN, LOW);   // 0 V にする → 消灯
  delay(500);
}
```

- `pinMode(ピン, OUTPUT)`：ピンを **出力** として使う設定です。ESP32 のピンは入力にも出力にも使えるので、最初にどちらで使うかを決めます
- `digitalWrite(ピン, HIGH / LOW)`：ピンの電圧を切り替えます。ESP32 では `HIGH` が 3.3 V、`LOW` が 0 V です
- `const int LED_PIN = 13;`：ピン番号を定数にしておくと、配線を変えたときに1か所直すだけで済みます

!!! mame "Lチカ"
    「**L**ED を **チカ**チカ点滅させる」の略で、日本の電子工作でよく使われる言葉です。マイコンの世界の「Hello, World」にあたり、新しいマイコンを触るときはまず Lチカから始めるのが定番です。

!!! mame "GPIO"
    **G**eneral **P**urpose **I**nput/**O**utput（汎用入出力）の略です。プログラムから入力にも出力にも切り替えて使える、汎用のピンを指します。`GPIO13` は「13 番の GPIO」という意味です。

## 抵抗が必要な理由

LED は、一定以上の電圧（赤色で約 2 V）がかかると急に大きな電流が流れる性質を持っています。抵抗をはさまずにつなぐと電流が流れすぎて、LED や ESP32 のピンが壊れることがあります。

抵抗の値は、オームの法則から求めます。

```
抵抗値 R =（電源電圧 − LED の電圧）÷ 流したい電流
         =（3.3 V − 2.0 V）÷ 6 mA
         ≒ 220 Ω
```

ESP32 のピンから流せる電流は、1 本あたり 20 mA 程度に抑えるのが安全です。LED は数 mA でも十分に光るので、この講座では 220 Ω を使います。

!!! mame "抵抗のカラーコード"
    抵抗の色の帯は、抵抗値を表しています。220 Ω は「赤・赤・茶」（4 本帯の場合、その後に誤差を表す金）です。
    読み間違えやすいので、慣れないうちはテスターで測って確かめるのが確実です。

## 発展課題

- [ ] 点滅の間隔を変えて、「速い点滅を 3 回 → 長い消灯」を繰り返すパターンにする
- [ ] LED をもう1つ追加し（GPIO14 など）、2つを交互に点滅させる
- [ ] モールス信号で `SOS`（・・・ − − − ・・・）を点滅させる

## うまくいかないとき

??? question "LED が点灯しない"
    - LED の向きが逆になっていないか確認してください（足が長い方を抵抗側に）
    - ブレッドボードの同じ列（縦 5 穴）に、つなぎたい部品の足が挿さっているか確認してください
    - コードの `LED_PIN` と、実際につないだピンの番号が一致しているか確認してください
    - GND につながっているか確認してください

??? question "LED が暗い"
    抵抗の値が大きすぎる可能性があります。カラーコードを確認してください（220 Ω は赤・赤・茶）。
