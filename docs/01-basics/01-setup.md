# 1. 環境構築

## このステップでやること

自分の PC に開発環境を入れて、ESP32 にプログラムを書き込めるようにします。
最後に、ESP32 から PC に「Hello」という文字列を送るプログラムを動かします。

この講座では、**VSCode**（エディタ）と **PlatformIO**（マイコン開発用の拡張機能）を使います。

!!! mame "エディタ・IDE・PlatformIO の違い"
    - **エディタ**：文字を書くための道具です。Windows のメモ帳もエディタの一種です。VSCode は高機能なエディタで、シンタックスハイライトや入力補完の機能を持っています。ただし、エディタだけではプログラムをビルド・実行できません。
    - **IDE（統合開発環境）**：プログラムの「記述」「ビルド（マイコン用への変換）」「書き込み」「動作確認」のための道具を、1つにまとめたソフトです。マイコン向けでは Arduino IDE が有名です。
    - **PlatformIO**：VSCode に追加する拡張機能です。マイコン開発に必要な道具（コンパイラ、書き込みツール、ライブラリ管理など）をまとめて提供します。

    つまり、エディタである **VSCode** に **PlatformIO** を追加することで、マイコン用の **IDE** として使えるようになります。

## 使うもの

- PC
- ESP32 ボード
- USB ケーブル（**データ通信に対応したもの**）

## 手順1：VSCode を入れる

1. [VSCode の公式サイト](https://code.visualstudio.com/) からインストーラーをダウンロードして、インストールする
2. 起動したら、左の拡張機能アイコン（四角が4つのアイコン）から `Japanese Language Pack` を検索してインストールすると、メニューが日本語になる（任意）

!!! todo "画像：VSCode の拡張機能アイコンの場所"

## 手順2：PlatformIO を入れる

1. VSCode の拡張機能で `PlatformIO IDE` を検索して、インストールする
2. インストールが終わるまで待つ（右下に進捗が表示されます。数分かかります）
3. 「Reload」を求められたら押して、VSCode を再起動する
4. 左側に **アリの顔のアイコン** が表示されれば成功

!!! todo "画像：PlatformIO のアイコンと PIO Home の画面"

## 手順3：ボードを PC につなぐ

ESP32 ボードと PC を USB ケーブルでつなぎます。ボードの電源 LED が点灯すれば問題ありません。

次に、PC がボードを認識しているか確認します。

=== "Windows"

    1. スタートボタンを右クリック →「デバイスマネージャー」を開く
    2. 「ポート (COM と LPT)」を開く
    3. `USB-SERIAL CH340 (COM3)` のような項目があれば認識できています（番号は環境によって異なります）

    「ポート」がない、または「ほかのデバイス」に「!」付きで表示されている場合は、ドライバを入れます。

    1. WCH（CH340 の製造元）の公式サイトから `CH341SER.EXE` をダウンロードする
    2. 実行して「INSTALL」を押す
    3. USB ケーブルを抜き差しして、もう一度デバイスマネージャーを確認する

    !!! todo "画像：デバイスマネージャーで認識できている画面"

=== "Mac"

    最近の macOS には CH340 のドライバが標準で入っているので、基本的にはつなぐだけで使えます。
    ターミナルで次のコマンドを実行して、`/dev/cu.wchusbserial...` や `/dev/cu.usbserial...` が表示されれば認識できています。

    ```sh
    ls /dev/cu.*
    ```

!!! mame "CH340 とは"
    ESP32 の多くは USB 通信の機能を持っていません（一部の新しい ESP32 を除く）。そこでボードには、USB の信号を ESP32 が扱える **シリアル通信（UART）** の信号に変換するチップが載っています。それが **CH340** です。
    PC 上の「COM3」などのポートは、この変換チップに対応しています。

## 手順4：プロジェクトを作る

PlatformIO では、プログラムを **プロジェクト** という単位で管理します。

1. アリのアイコン →「PIO Home」→「Open」→「New Project」を押す
2. 次のように入力して「Finish」を押す

    | 項目 | 入力する内容 |
    |---|---|
    | Name | `hello`（日本語や空白は使わない） |
    | Board | `Espressif ESP32 Dev Module` |
    | Framework | `Arduino` |
    | Location | 「Use default location」のチェックを外して、`C:\esp32` などのフォルダを選ぶ（下の注意を参照） |

3. 初回は ESP32 用のツールをダウンロードするので、数分待つ

!!! warning "フォルダの場所に注意"
    プロジェクトを置くフォルダのパス（途中のフォルダも含む）に **日本語や空白が含まれていると、ビルドに失敗することがあります**。
    Windows のユーザー名が日本語の場合は特に注意し、`C:\esp32` のような英数字だけのパスにプロジェクトを作成してください。

!!! todo "画像：New Project の入力画面"

プロジェクトを作成すると、次のファイルが作られます。

```
hello/
├── platformio.ini   ← ボードや設定を書くファイル
└── src/
    └── main.cpp     ← ここにプログラムを書く
```

## 手順5：設定を書く

`platformio.ini` を開いて、次のように書き換えます。`platform` の行に `@ 6.9.0` を追加し、最後に `monitor_speed = 115200` の1行を追加します。

```ini title="platformio.ini"
[env:esp32dev]
platform = espressif32 @ 6.9.0
board = esp32dev
framework = arduino
monitor_speed = 115200
```

`@ 6.9.0` は、ESP32 用の開発ツールのバージョンの指定です。この講座のプログラムは、すべてこのバージョンで動作を確認しています。指定しないと最新版が使われ、講座のプログラムがそのままでは動かないことがあります。**以降のステップでも、プロジェクトを作るたびにこの `platformio.ini` を使ってください。**

`monitor_speed` は、ESP32 と PC が通信するときの速度です（PlatformIO のシリアルモニタを使うときの設定）。プログラム側の速度（後で出てくる `Serial.begin(115200)`）と合わせる必要があります。

!!! mame "115200 という半端な数字"
    この速度の単位は **bps**（1秒間に送るビット数）で、ボーレートとも呼ばれます。115200 は 9600 の12倍で、モデムの時代から使われてきた標準的な速度の1つです。
    送信側と受信側で速度が異なると、ビットの区切りがずれて文字化けします。

## 手順6：プログラムを書く

`src/main.cpp` の中身をすべて消して、次のプログラムに書き換えます。

```cpp title="src/main.cpp"
#include <Arduino.h>

// 電源が入ったときに、1回だけ実行される
void setup() {
  Serial.begin(115200);  // PCとの通信を始める
}

// setup() のあと、繰り返し実行される
void loop() {
  Serial.println("Hello, ESP32!");  // PCに文字列を送る
  delay(1000);                      // 1000ミリ秒（1秒）待つ
}
```

マイコンのプログラムは、`setup()` と `loop()` の2つの関数で構成されます。

- `setup()`：電源が入ったときに **1回だけ** 実行される。初期設定を行う場所
- `loop()`：`setup()` のあと、電源が入っている間 **繰り返し** 実行される

[0. マイコンとは？](../00-intro/index.md) で説明した「入力 → 処理 → 出力の繰り返し」は、この `loop()` の中に書いていきます。

## 手順7：書き込む

VSCode の一番下（ステータスバー）に、PlatformIO のボタンが並んでいます。

| ボタン | 名前 | 機能 |
|---|---|---|
| ✓ | Build | プログラムをマイコン用に変換する（エラーの有無を確認できる） |
| → | Upload | ビルドして、ESP32 に書き込む |

!!! todo "画像：ステータスバーのボタンの場所"

!!! mame "ビルドの中身"
    C++ で書いたプログラムは、そのままではマイコンで実行できません。**ビルド** では、プログラムをマイコンが直接実行できる機械語に変換しています。この変換を行うのが **コンパイラ** です。
    `delay()` や `Serial` などのライブラリの機能も、このときにまとめて組み込まれます。

1. **→（Upload）** を押す
2. 下のターミナルに `SUCCESS` と表示されれば書き込み成功

## 手順8：シリアルモニタで見る

ESP32 から送られてきた文字列は、**シリアルモニタ**（ターミナルソフト）で確認します。
PlatformIO にもシリアルモニタは付属していますが、操作しづらいので、この講座では専用のソフトを使います。

=== "Windows：Tera Term"

    **インストール**

    1. Tera Term Project の公式サイト（GitHub）から、最新版のインストーラー（`teraterm-x.x.exe`）をダウンロードする
    2. インストーラーを実行する。設定はすべて既定のままで構いません

    **初回の設定**

    1. Tera Term を起動すると「新しい接続」の画面が表示されるので、「シリアル」を選び、ポートを `COM3: USB-SERIAL CH340 (COM3)` のような ESP32 のポートにして「OK」を押す
    2. メニューの「設定」→「シリアルポート」を開き、**スピードを `115200`** にして「現在の接続設定」を押す
    3. 「設定」→「設定の保存」を押して、そのまま保存する（次回からスピードの変更が不要になります）

    !!! todo "画像：Tera Term の新しい接続・シリアルポート設定の画面"

    `Hello, ESP32!` が1秒ごとに表示されれば成功です。

=== "Mac：CoolTerm"

    Tera Term は Windows 専用なので、Mac では **CoolTerm** を使います。

    1. CoolTerm の公式サイトから Mac 版をダウンロードして、アプリケーションフォルダに入れる
    2. 起動して「Options」を開き、Port を `usbserial-...` や `wchusbserial-...`、Baudrate を **`115200`** にして「OK」を押す
    3. 「Connect」を押す

    `Hello, ESP32!` が1秒ごとに表示されれば成功です。

!!! warning "書き込む前にシリアルモニタを切断する"
    シリアルモニタがポートを使用している間は、**PlatformIO から書き込めません**（`Could not open port` などのエラーが出ます）。
    プログラムを修正して書き込むときは、次の手順で行ってください。

    1. シリアルモニタを切断する（Tera Term：「ファイル」→「接続断」、CoolTerm：「Disconnect」）
    2. PlatformIO で Upload する
    3. シリアルモニタを再接続する（Tera Term：「ファイル」→「新しい接続」、CoolTerm：「Connect」）

!!! mame "Tera Term は日本製"
    Tera Term は、1990年代に寺西 高 氏が開発したソフトです。名前の「Tera」は開発者の名前に由来します。
    現在は有志の「Tera Term Project」が開発を引き継いでおり、マイコンやネットワーク機器の開発で広く使われています。

!!! note "PlatformIO のシリアルモニタを使う場合"
    ステータスバーの 🔌（コンセント）ボタンを押すと、VSCode の中でシリアルモニタが開きます。速度は `platformio.ini` の `monitor_speed` で決まります。終了するときは ++ctrl+c++ を押します。

## 発展課題

- [ ] 表示する文字列を自分の名前に変える
- [ ] `delay(1000)` の値を変えて、表示の間隔を変える
- [ ] `setup()` の中に `Serial.println("start");` を追加し、いつ表示されるかを確かめる（ヒント：ボードの EN ボタンを押す）

## うまくいかないとき

??? question "書き込みで `Failed to connect to ESP32: ... Timed out waiting for packet header` と表示される"
    ESP32 が書き込みモードに入れていません。
    もう一度 Upload を押し、ターミナルに `Connecting....` と表示されている間、**ボードの BOOT ボタンを押し続けて** ください。書き込みが始まったら離して構いません。

??? question "書き込みで `Could not open port` や `Access is denied` と表示される"
    - Tera Term などのシリアルモニタが接続したままだと、書き込みに使うポートを使用できません。シリアルモニタを切断してから、もう一度書き込んでください（手順8の注意を参照）
    - 別のウィンドウで Tera Term が開いたままになっていないかも確認してください

??? question "ポートが見つからない・デバイスマネージャーに表示されない"
    - USB ケーブルが **充電専用** の可能性があります。別のケーブルで試してください
    - ドライバが入っていない可能性があります。手順3をもう一度確認してください
    - PC の別の USB 端子に挿してみてください

??? question "シリアルモニタの文字が化ける（`⸮⸮⸮` のようになる）"
    シリアルモニタの速度と、プログラムの `Serial.begin()` の値が一致しているか確認してください。どちらも `115200` にします。

    - Tera Term：「設定」→「シリアルポート」のスピード
    - CoolTerm：「Options」の Baudrate
    - PlatformIO のシリアルモニタ：`platformio.ini` の `monitor_speed`

    電源を入れた直後や EN ボタンを押した直後だけ文字化けするのは、ESP32 が起動時に別の速度でメッセージを出力しているためで、問題ありません。

??? question "ビルドが失敗する・初回のビルドが非常に遅い"
    - 初回はツールのダウンロードがあるので、数分〜十数分かかることがあります
    - プロジェクトのフォルダのパスに日本語や空白が含まれていないか確認してください（手順4の注意を参照）
