## この講座で使うピン

講座の各ステップでは、ピンが重ならないように、次の割り当てで統一しています。複数のステップを組み合わせるときも、そのまま使えます。

| ピン | 用途 | 使うステップ |
|---|---|---|
| GPIO4 | タクトスイッチ | ボタン入力、delay を使わない書き方、ESP-NOW、赤外線 |
| GPIO13 | LED | Lチカ 〜 アナログ入力、Wi-Fi、BLE、ESP-NOW |
| GPIO18 | サーボモーターの信号 | サーボモーター |
| GPIO21 | I2C の SDA | I2C センサー、OLED ディスプレイ |
| GPIO22 | I2C の SCL | I2C センサー、OLED ディスプレイ |
| GPIO23 | 赤外線 LED | 赤外線 |
| GPIO25 | モータードライバ AIN1 | DC モーター |
| GPIO26 | モータードライバ AIN2 | DC モーター |
| GPIO27 | モータードライバ PWMA | DC モーター |
| GPIO32 | 可変抵抗 | アナログ入力、OLED ディスプレイ、サーボモーター、DC モーター |
| GPIO34 | 赤外線受信モジュール | 赤外線 |
| GPIO14、19、33 | モータードライバ BIN1、BIN2、PWMB | DC モーター（発展課題） |

## 使うときに注意が必要なピン

| ピン | 注意点 |
|---|---|
| GPIO0、2、5、12、15 | **ストラッピングピン**。起動時の電圧で ESP32 の動作モードが決まるので、つなぐ部品によっては起動しなくなったり、書き込めなくなったりする |
| GPIO1、3 | USB シリアル（TX、RX）に使われている。使うとシリアルモニタや書き込みができなくなる |
| GPIO6〜11 | 内部のフラッシュメモリに使われている。**使用禁止** |
| GPIO16、17 | WROVER モジュールの場合、PSRAM に使われている |
| GPIO34〜39 | **入力専用**。出力には使えず、内蔵プルアップ・プルダウンもない |
| ADC2 のピン（GPIO0、2、4、12〜15、25〜27） | Wi-Fi を使っている間は、アナログ入力に使えない |

!!! note "ボードの型番による違い"
    この表は、ESP32（WROOM / WROVER）を搭載したボードのものです。ESP32-S3 などを搭載したボードでは、ピンの番号や役割が異なります。

!!! mame "ストラッピングピン"
    ESP32 は、電源を入れた瞬間に一部のピンの電圧を読み取り、「プログラムを実行するか、書き込みを待つか」などを決めています。このピンを **ストラッピングピン** と言います。
    ボードの BOOT ボタンは、GPIO0 を GND につなぐボタンです。押しながら起動すると、書き込みを待つモードになります。
