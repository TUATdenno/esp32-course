# マイコン＋ESP32 講座

マイコン（ESP32）を使って、LED を光らせたり、センサーで測ったり、モーターを動かしたりする方法を学ぶ講座です。
講座を終えたら、**作りたいものに必要な部品やコードを、自分で調べながら作れる**ようになることを目指します。

## 持ち物

- **ノート PC**（Windows / Mac）
- USB ケーブルやボード、部品はサークルで用意します

## 進め方

- 部室に来たときに、**自分のペースで**このテキストを進めてください
- 1つのステップは 30分〜1時間くらいで終わる量です。時間があれば、その日に進められるだけ進めて構いません
- 分からないところ・うまく動かないところは、部室にいる先輩に気軽に聞いてください
- 各ステップの最後にある **チェックポイント** までできたら、先輩に見せて進捗表にチェックをもらいましょう

!!! tip "詰まったときは"
    各ステップの「うまくいかないとき」に、よくある失敗とその対処をまとめています。まずはそこを確認し、それでも解決しなければ先輩に聞いてください。
    15分以上ひとりで悩むより、早めに聞いたほうが効率よく進められます。
