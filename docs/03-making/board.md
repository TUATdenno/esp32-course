# 回路を作る

## このステップでやること

ブレッドボードで作った回路を、ユニバーサル基板にはんだ付けして作り直します。
ブレッドボードは試作に便利ですが、振動で線が抜けやすく、作品に組み込むには向いていません。はんだ付けした基板にすることで、壊れにくく、小さくまとまった回路になります。

## 前提ステップ・使う部品

- 前提：第1部（ブレッドボードで動作を確認した回路があること）
- 部品・道具：
    - ユニバーサル基板
    - ピンソケット（ESP32 ボードを挿すため）
    - スズメッキ線、またはジャンパ用の電線
    - はんだごて、こて台、はんだ、こて先クリーナー
    - ニッパー、ピンセット
    - テスター

!!! warning "はんだ付けの安全"
    - はんだごての先端は **300 ℃ 以上** になります。使わないときは必ずこて台に置いてください
    - はんだ付けで出る煙を直接吸わないように、換気するか、吸煙器を使ってください
    - 作業が終わったら、はんだごての電源を切ったことを確認してください
    - はんだに触れた手で飲食しないでください。作業後は手を洗ってください
    - 初めての人は、先輩の前で練習してから作業してください

## 手順1：回路図を描く

いきなり基板にはんだ付けを始めると、配線を間違えたり、部品が入りきらなかったりします。まずは、ブレッドボードで動いた回路を **回路図** にします。

1. ESP32 のどのピンに、何の部品をつないでいるかを書き出す
2. 電源（3V3、5V）と GND のつながりを書き出す
3. 回路図にまとめる（手書きでも、KiCad などのソフトでも構いません）

## 手順2：部品の配置を決める

方眼紙や、基板の穴と同じ間隔のマス目の紙に、部品の配置と配線を描きます。

- ESP32 ボードは **ピンソケット** に挿す形にし、直接はんだ付けしない（壊れたときに交換でき、ほかの作品にも使い回せる）
- 電源と GND の配線は、太く短くする
- 配線が交差しないように、部品の向きや位置を工夫する
- 基板の **裏から見ると左右が反転する** ことに注意する

!!! todo "画像：配置図の例"

## 手順3：はんだ付けする

1. 背の低い部品（抵抗など）から順にはんだ付けする
2. ピンソケットは、ESP32 ボードを挿した状態ではんだ付けすると、まっすぐ付けられる（熱で ESP32 が傷まないよう、手早く行う）
3. 配置図を見ながら、配線をはんだ付けする

!!! todo "画像：はんだ付けの良い例と悪い例"

!!! mame "良いはんだ付け"
    良いはんだ付けは、はんだが富士山のような形に広がり、表面がつやつやしています。丸い玉のようになっていたり、表面がざらざらしていたりする場合は、はんだが部品や基板に十分なじんでいません（**イモはんだ**）。接触不良の原因になるので、やり直してください。
    コツは、はんだごてで **部品の足と基板の両方** を 2〜3 秒温めてから、はんだを当てることです。

## 手順4：確認してから電源を入れる

はんだ付けが終わっても、すぐに電源を入れてはいけません。

1. はんだ付けした部分を目で見て、隣の配線とはんだがくっついていないか確認する
2. テスターの **導通チェック** で、つながるべきところがつながっているか確認する
3. テスターの導通チェックで、**3V3 と GND、5V と GND がつながっていない**（ショートしていない）ことを必ず確認する
4. ESP32 ボードを挿さずに電源を入れ、各部の電圧をテスターで測る
5. 問題がなければ、ESP32 ボードを挿して動作を確認する

!!! mame "導通チェック"
    テスターの導通チェックのモードでは、2 本のテスト棒の間が電気的につながっていると、ブザーが鳴ります。配線が正しくつながっているかや、ショートしていないかを、電源を入れずに確認できます。

## 発展課題

- [ ] センサーやモーターを **コネクタ** でつなぐようにして、外したり交換したりできるようにする
- [ ] KiCad で回路図を描き、プリント基板の設計に挑戦する

## うまくいかないとき

??? question "はんだが部品になじまない"
    - こて先が汚れていると熱が伝わりにくくなります。こて先クリーナーで掃除してください
    - 部品の足と基板の両方を温めてから、はんだを当ててください

??? question "電源を入れたら動かない"
    すぐに電源を切ってください。テスターで、ショートしている箇所や、つながっていない箇所がないかを確認してください。

## チェックポイント

!!! success "チェックポイント"
    はんだ付けした基板で、ブレッドボードのときと同じように動作したら、先輩に見せて進捗表にチェックをもらってください。
