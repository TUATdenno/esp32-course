# 第2部 応用

第2部では、センサー・ディスプレイ・モーター・無線通信など、作品づくりでよく使う技術を扱います。
各ステップは独立しているので、**作りたいものに必要なものだけを選んで** 進めてください。どのステップも、第1部を終えていることが前提です。

| 分野 | ステップ | できるようになること | 追加の前提 |
|---|---|---|---|
| センサー | [I2C センサー](i2c-sensor.md) | 温度・湿度・気圧を測る | なし |
| 表示 | [OLED ディスプレイ](oled.md) | 小さな画面に文字や図形を表示する | I2C センサー（I2C の説明） |
| 動かす | [サーボモーター](servo.md) | 決まった角度まで回す | なし |
| 動かす | [DC モーター](dc-motor.md) | 回転の速さと向きを変える | なし |
| 無線 | [Wi-Fi（Web サーバ）](wifi.md) | スマホのブラウザから操作する | なし |
| 無線 | [BLE](ble.md) | スマホのアプリと通信する | なし |
| 無線 | [ESP-NOW](esp-now.md) | ESP32 同士で直接通信する | なし |
| 赤外線 | [赤外線の送受信](ir.md) | リモコンの信号を読み取る・送る | なし |

## 選び方の例

| 作りたいもの | 必要なステップ |
|---|---|
| 部屋の温湿度を表示する装置 | I2C センサー、OLED ディスプレイ |
| スマホで操作できるライト | Wi-Fi または BLE |
| ラジコンカー | DC モーター、ESP-NOW |
| 自動で開くゴミ箱 | サーボモーター（＋距離センサー） |
| 家電を操作する学習リモコン | 赤外線の送受信、Wi-Fi |

## ライブラリについて

第2部では、部品を簡単に扱うための **ライブラリ** を使います。ライブラリは、`platformio.ini` の `lib_deps` に書くと、ビルドするときに PlatformIO が自動でダウンロードします。

```ini
lib_deps =
    adafruit/Adafruit BME280 Library @ ^2.2.4
```

ライブラリの名前は、PIO Home の「Libraries」で検索して調べられます。

!!! mame "ライブラリのバージョン指定"
    `@ ^2.2.4` は「2.2.4 以上で、3.0.0 未満の最新版」という意味です。メジャーバージョン（先頭の数字）が変わると使い方が変わることが多いので、このように範囲を指定しておくと、将来ライブラリが更新されてもプログラムが動かなくなりにくくなります。
