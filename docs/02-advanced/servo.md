# サーボモーター

## このステップでやること

サーボモーターを、可変抵抗のつまみに合わせて動かします。
サーボモーターは、指定した角度まで回って止まるモーターです。ロボットの関節や、扉の開け閉めなどに使われます。

## 配線

SG90 には、3 色の線が出ています。

| SG90 の線 | 接続先 |
|---|---|
| 茶（GND） | ESP32 の GND |
| 赤（電源） | ESP32 の 5V（VIN） |
| オレンジ（信号） | ESP32 の GPIO18 |

可変抵抗は [6. アナログ入力](../01-basics/06-analog.md) と同じです（3V3、GPIO32、GND）。

!!! warning "サーボの電源"
    サーボモーターは動き始めに大きな電流が流れるので、3.3 V ではなく **5V（VIN）ピン** から電源をとります。USB から給電している間は、5V ピンに USB の 5 V が出ています。
    2 個以上のサーボを使う場合や、大きなサーボを使う場合は、電流が足りなくなって ESP32 が再起動することがあります。その場合は、サーボ用に別の電源を用意してください（GND は ESP32 と共通にします）。

## サーボモーターの仕組み

サーボモーターは、**PWM のパルスの幅** で角度を指定します。

| パルスの幅 | 角度（SG90 の場合） |
|---|---|
| 約 0.5 ms | 0° |
| 約 1.45 ms | 90° |
| 約 2.4 ms | 180° |

このパルスを 20 ms（50 Hz）ごとに送り続けます。サーボの中には、モーターと角度を測るセンサー、制御回路が入っていて、指定された角度になるように自動でモーターを回します。

## コード

```ini title="platformio.ini"
[env:esp32dev]
platform = espressif32 @ 6.9.0
board = esp32dev
framework = arduino
monitor_speed = 115200
lib_deps =
    madhephaestus/ESP32Servo @ ^3.0.6
```

```cpp title="src/main.cpp"
#include <Arduino.h>
#include <ESP32Servo.h>

const int SERVO_PIN = 18;
const int POT_PIN = 32;

Servo servo;

void setup() {
  Serial.begin(115200);
  servo.setPeriodHertz(50);           // 50 Hz（20 ms 周期）
  servo.attach(SERVO_PIN, 500, 2400); // 0° と 180° のパルス幅（µs）
}

void loop() {
  int raw = analogRead(POT_PIN);
  int angle = map(raw, 0, 4095, 0, 180);

  servo.write(angle);  // 角度を指定する（0〜180°）
  Serial.printf("angle = %d\n", angle);
  delay(20);
}
```

- `servo.attach(ピン, 最小パルス幅, 最大パルス幅)`：サーボをつないだピンと、0° と 180° に対応するパルス幅を指定します
- `servo.write(角度)`：サーボを指定した角度まで動かします

!!! mame "サーボの種類"
    SG90 のように角度を指定するもののほか、**連続回転サーボ** というものもあります。こちらは角度ではなく回転の速さと向きを指定するもので、小型の車輪の駆動などに使われます。
    見た目はほとんど同じなので、型番を確認してから使ってください。

## 発展課題

- [ ] つまみを使わずに、0° と 180° の間を自動で往復させる
- [ ] [4. ボタン入力](../01-basics/04-button.md) の回路を追加し、ボタンを押すたびに 0° → 90° → 180° と切り替える
- [ ] 急に動かず、目標の角度までゆっくり動くようにする（ヒント：1 回の `loop()` で 1° ずつ近づける）

## うまくいかないとき

??? question "サーボが動かない"
    - 信号線（オレンジ）が GPIO18 につながっているか確認してください
    - 電源（赤）が 5V（VIN）ピンにつながっているか確認してください

??? question "サーボが動くと ESP32 が再起動する"
    電流が足りていません。PC の別の USB 端子を使うか、サーボ用の電源を別に用意してください。

??? question "端まで回すと、ジジジと音がして震える"
    サーボが動ける範囲の限界を超えて回そうとしています。`attach` のパルス幅を、`500, 2400` から `600, 2300` のように少し狭めてください。
