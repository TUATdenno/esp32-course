# DC モーター

## このステップでやること

モータードライバを使って DC モーターを回し、可変抵抗のつまみで回転の速さと向きを変えます。
車輪で走るロボットや、ファン、ポンプなど、回転させて動かすものの基本になります。

## 前提ステップ・使う部品

- 前提：第1部（特に [5. PWM](../01-basics/05-pwm.md)、[6. アナログ入力](../01-basics/06-analog.md)）
- 部品：
    - DC モーター（ギアボックス付きのもの）× 1
    - モータードライバ（TB6612FNG モジュール）× 1
    - 電池ボックス（単 3 × 4 本、6 V）× 1
    - 可変抵抗（10 kΩ）× 1
    - ジャンパワイヤ

## モータードライバが必要な理由

DC モーターは、回すのに数百 mA 以上の電流が必要です。ESP32 のピンから流せるのは 20 mA 程度なので、モーターを直接つなぐことはできません。
**モータードライバ** は、ESP32 からの小さな信号を受け取り、別の電源から大きな電流をモーターに流すための IC です。さらに、電流の向きを切り替えて、モーターを逆回転させることもできます。

!!! mame "H ブリッジ"
    モーターの回転の向きを切り替える回路を **H ブリッジ** と言います。4 つのスイッチ（トランジスタ）をアルファベットの H の形に並べ、対角のスイッチを入れる組み合わせで、モーターに流れる電流の向きを変えます。
    TB6612FNG の中には、この H ブリッジが 2 組入っていて、モーターを 2 個まで制御できます。

## 配線

| TB6612FNG | 接続先 |
|---|---|
| VM | 電池ボックスの ＋（モーター用の電源） |
| VCC | ESP32 の 3V3（ドライバの IC 用の電源） |
| GND | ESP32 の GND、電池ボックスの − |
| STBY | ESP32 の 3V3（常に動作させる） |
| AIN1 | ESP32 の GPIO25 |
| AIN2 | ESP32 の GPIO26 |
| PWMA | ESP32 の GPIO27 |
| AO1、AO2 | モーターの 2 本の線 |

可変抵抗は [6. アナログ入力](../01-basics/06-analog.md) と同じです（3V3、GPIO32、GND）。

!!! warning "GND を共通にする"
    ESP32 の GND と電池の −（GND）は、必ずつないでください。GND がつながっていないと、ESP32 からの信号の電圧の基準が合わず、正しく動作しません。

!!! warning "電池をつなぐのは最後"
    配線を変えるときは、必ず電池ボックスのスイッチを切るか、電池を外してから作業してください。

## モーターの制御方法

TB6612FNG では、AIN1・AIN2 の組み合わせで回転の向きを、PWMA の PWM で速さを決めます。

| AIN1 | AIN2 | 動作 |
|---|---|---|
| HIGH | LOW | 正転 |
| LOW | HIGH | 逆転 |
| LOW | LOW | 停止（惰性で止まる） |
| HIGH | HIGH | ブレーキ（急に止まる） |

## コード

```cpp title="src/main.cpp"
#include <Arduino.h>

const int AIN1 = 25;
const int AIN2 = 26;
const int PWMA = 27;
const int POT_PIN = 32;

// speed：-255（逆転・最大）〜 0（停止）〜 255（正転・最大）
void setMotor(int speed) {
  if (speed > 0) {
    digitalWrite(AIN1, HIGH);
    digitalWrite(AIN2, LOW);
  } else if (speed < 0) {
    digitalWrite(AIN1, LOW);
    digitalWrite(AIN2, HIGH);
  } else {
    digitalWrite(AIN1, LOW);
    digitalWrite(AIN2, LOW);
  }
  analogWrite(PWMA, abs(speed));  // 速さは PWM のデューティ比で決める
}

void setup() {
  Serial.begin(115200);
  pinMode(AIN1, OUTPUT);
  pinMode(AIN2, OUTPUT);
  pinMode(PWMA, OUTPUT);
}

void loop() {
  int raw = analogRead(POT_PIN);
  int speed = map(raw, 0, 4095, -255, 255);  // つまみの中央で停止

  // 中央付近は停止にする（つまみを中央にしても完全に 0 にはならないため）
  if (abs(speed) < 30) {
    speed = 0;
  }

  setMotor(speed);
  Serial.printf("speed = %d\n", speed);
  delay(50);
}
```

`setMotor()` のように、よく使う処理を関数にまとめておくと、プログラムが読みやすくなります。2 輪の車を作る場合は、左右のモーターそれぞれに `setMotor` を用意し、左右の速さの差で曲がるように制御します。

!!! mame "モーターを遅くすると回らない"
    PWM のデューティ比を小さくしていくと、ある値より下ではモーターが回らなくなります。モーターやギアの摩擦に打ち勝つだけの力が出ないためです。
    また、モーターの個体差で、同じデューティ比でも回転の速さが少しずつ違います。2 輪の車がまっすぐ走らないのは、このためです。

!!! mame "逆起電力とノイズ"
    モーターは、回転すると発電機としても働き、電源と逆向きの電圧（逆起電力）を発生させます。また、内部のブラシが擦れるときに電気的なノイズも出します。
    ESP32 とモーターの電源を分けているのは、このノイズで ESP32 が誤動作するのを防ぐためでもあります。モーターの端子に 0.1 µF のコンデンサをはんだ付けすると、ノイズを減らせます。

## 発展課題

- [ ] つまみを使わずに、「正転 2 秒 → 停止 1 秒 → 逆転 2 秒 → 停止 1 秒」を繰り返す
- [ ] 急に速さを変えず、少しずつ加速・減速するようにする
- [ ] モーターをもう 1 つ追加し（BIN1：GPIO14、BIN2：GPIO19、PWMB：GPIO33）、2 つのモーターを逆向きに回す

## うまくいかないとき

??? question "モーターが回らない"
    - 電池ボックスのスイッチが入っているか、電池が消耗していないか確認してください
    - STBY が 3V3 につながっているか確認してください。STBY が LOW だと、ドライバは動作しません
    - ESP32 の GND と電池の − がつながっているか確認してください

??? question "つまみを中央にしても止まらない"
    `abs(speed) < 30` の `30` を大きくして、停止とみなす範囲を広げてください。

??? question "モーターが回ると ESP32 が再起動する"
    モーターのノイズや電源の電圧低下が原因です。モーターの電源が ESP32 と分かれているか確認し、モーターの端子にコンデンサを付けてください。
